Getting Started

Install OmniDeck and get a service on the screen in a few minutes.

Install

  1. Download the installer. Grab the Windows build from the Downloads page and run it. No account or sign-in is required.
  2. Open OmniDeck. The Library opens first — this is where every saved presentation lives.

Build a service

  1. Create or open a presentation from the Library — start fresh, or reopen last week's service to build on it.
  2. Add slides for scripture, songs, media, and announcements. Each one autosaves as you go, so there's nothing to remember to save.
  3. Preview each slide in the controller before you're live, using the same renderer that will drive the projector.

Go live

  1. Choose Start Output. Pick Display Output for a fullscreen window on this computer — the usual choice for a projector or a second monitor — or Web Output to get a URL for OBS, a tablet, or another computer on the network.
  2. Run the service from the controller: step through the playlist, and use Blackout any time you need to cut to black instantly.
OmniDeck's Local mode runs entirely offline — nothing above requires an internet connection. Cloud sync is optional, for teams that need a second controller to stay in sync remotely.
