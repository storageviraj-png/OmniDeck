OBS Setup

Send OmniDeck's output straight into OBS using a Browser Source — no capture card, no separate renderer to keep in sync.

Steps

  1. In OmniDeck's controller, choose Start Output → Web Output.
  2. Copy the generated Output URL. It's a private, hard-to-guess link tied to this installation — not a public page.
  3. In OBS, add a new Browser Source, paste the URL in, and set its resolution to match your stream canvas (1920×1080 is a safe default).
  4. Leave "Shutdown source when not visible" unchecked, so OmniDeck keeps rendering in the background between cues.
  5. Resize and position the source in your scene like any other layer.

Why this works

The Browser Source loads the exact same output page and renderer that drives the projector — there's no OBS-specific version to fall out of sync. Whatever is live on screen is what OBS sees.

Using a second computer instead of OBS? The same Output URL works there too — paste it into any browser, on a tablet, a TV, or another PC on the network.
