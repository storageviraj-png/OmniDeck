Frequently asked questions

Offline use, syncing, platforms, and licensing.

Is OmniDeck free?

Yes. OmniDeck is free and open source, released under the MIT License. The full source is on GitHub.

Does it need an internet connection to run a service?

No. Local mode runs entirely on your own network and works fully offline. Cloud sync is optional, for teams that need a second controller to stay in sync remotely.

What platforms are supported?

Windows is available today. macOS and Linux builds are in progress — see Downloads for status.

Where is my presentation data stored?

Locally on your computer, with autosave on every edit. If you turn on cloud sync, presentations also sync to your own project — OmniDeck doesn't store your data on servers it operates.

Can I use OmniDeck with OBS?

Yes — see OBS Setup. It uses a plain Browser Source pointed at OmniDeck's Web Output, no plugin required.

Is there a mobile app?

Not yet. OmniDeck today is a Windows, macOS, and Linux desktop application.
